# ✧ LUMEN — Последний круг

Небольшая браузерная игра на выживание в духе Magic Survival / Vampire Survivors: управляй магом, уклоняйся от врагов, собирай опыт и усиливай автоматические заклинания. Оригинальные название, графика и код; сторонние игровые ресурсы не используются.

**Цель:** пережить 3 минуты и встретить рассвет. Поле бесконечное: камера следует за магом, а враги появляются вокруг текущей позиции. Здоровье видно и в верхнем интерфейсе, и прямо над персонажем. Игра работает на компьютере и телефоне, не требует аккаунта или сервера с базой данных.

## Самый простой запуск: один HTML-файл

1. [Скачай LUMEN.html](https://github.com/Alexanderio1/Magic_SurVvV/raw/refs/heads/main/LUMEN.html). Если браузер показывает текст, сохрани страницу как **LUMEN.html**, без расширения `.txt`.
2. Открой скачанный файл двойным щелчком в Chrome, Firefox, Edge или Safari на компьютере.
3. Нажми **«Войти в рощу»** и играй.

В этом файле уже находятся код, оформление и графика игры. Для игры не нужны Node.js, Python, терминал, localhost или интернет. Файл можно переименовать и перенести в другую папку. Содержимое автономного HTML проверено в Chromium с отключённой сетью. Прямая проверка открытия через `file://` в облачной среде недоступна из-за политики её браузера.

Для игры нужен именно **LUMEN.html**. `index.html` — отдельная версия для разработки и размещения на сайте; её запуск описан ниже. На телефоне открытие скачанных HTML-файлов зависит от браузера и файлового менеджера; также можно использовать опубликованный сайт.

## Запуск исходников для разработки (необязательно)

Нужны [Git](https://git-scm.com/downloads) и [Node.js 20+](https://nodejs.org/) (рекомендуется Node.js 24 LTS).

```bash
git clone https://github.com/Alexanderio1/Magic_SurVvV.git
cd Magic_SurVvV
npm start
```

Открой **http://localhost:5173** в современном Chrome, Firefox, Edge или Safari. Для остановки нажми `Ctrl+C` в терминале. `npm install` не нужен: внешних зависимостей нет.

Альтернативный запуск с Python 3, из каталога проекта:

```bash
python3 -m http.server 5173 --bind 127.0.0.1
```

На Windows команда может называться `python` или `py`. Версия `index.html` загружает JavaScript-модули через HTTP. Чтобы играть двойным щелчком, используй готовый `LUMEN.html`.

Для игры с телефона в той же локальной сети запусти сервер на всех интерфейсах:

```bash
# macOS / Linux
HOST=0.0.0.0 npm start
```

```powershell
# Windows PowerShell
$env:HOST="0.0.0.0"; npm start
```

На телефоне открой `http://<локальный-IP-компьютера>:5173`; доступ должен быть разрешён локальным брандмауэром. Другой порт задаётся переменной `PORT`.

## Как играть

| Действие | Компьютер | Телефон |
| --- | --- | --- |
| Движение | WASD / стрелки (любая раскладка) | Джойстик слева |
| Рывок с краткой неуязвимостью | Пробел | Кнопка ↯ справа |
| Пауза / продолжить | P / Esc / кнопка Ⅱ | Кнопка Ⅱ |
| Выбор улучшения | 1, 2, 3 / мышь | Нажатие на карточку |

Стрелы автоматически летят к ближайшим врагам. Перед забегом выбери ещё одно стартовое заклинание. Подбирай зелёные осколки: опыт даётся только за их сбор. Стоимость следующих уровней растёт: **10 → 15 → 21 → 28 → 37 → …**; текущее значение видно на шкале опыта. Само по себе время уровней не даёт.

На каждом уровне выбирай одно из трёх усилений: новое заклинание, ранг изученной магии или пассивное улучшение. Новые уровни также восстанавливают 8 здоровья. У большинства заклинаний 5 рангов, у вращающихся лун — 4. Пассивные усиления увеличивают урон всей магии, частоту заклинаний, число базовых стрел, скорость, радиус подбора, здоровье и регенерацию.

## Темы и облики за достижения

Темы поля и облики врагов выбираются независимо в «Коллекции обликов». Они меняют рисунок, формы и палитру, не характеристики противников. Новые варианты открываются сразу после выполнения условий; смена оформления во время забега ставит игру на паузу.

| Категория | Вариант | Условие |
| --- | --- | --- |
| Поле | Сумеречная роща | Доступно сразу |
| Поле | Ледяные пустоши | Выжить 60 секунд в одном забеге |
| Поле | Пепельные земли | Победить 100 врагов суммарно |
| Поле | Астральный сад | Выиграть забег |
| Враги | Тени | Доступно сразу |
| Враги | Кристаллы | Достичь 5-го уровня |
| Враги | Угольки | Победить 250 врагов суммарно |
| Враги | Древние маски | Изучить 6 видов магии в одном забеге, включая базовую |

Достижения, выбранное оформление и рекорд сохраняются локально в браузере. При недоступном хранилище они работают до закрытия страницы.

Каждые 45 секунд начинается более плотная волна. Постепенно появляются быстрые духи и тяжёлые враги. Рывок восстанавливается за 4 секунды. На 03:00 наступает победа; при потере всего здоровья можно сразу начать новый забег.

При уходе с вкладки игра ставится на паузу. Лучший результат хранится локально, если браузер разрешает хранилище; при очистке данных или перемещении HTML-файла он может сброситься. Недоступное хранилище не мешает играть. Звук по умолчанию выключен, его можно включить в шапке.

## Проверка и сборка

```bash
npm test
npm run build
```

34 теста проверяют бесконечное движение, появление врагов вокруг камеры, кривую опыта, все заклинания, рывок, паузу, победу, достижения и сохранение оформления. Сборка обновляет готовый **LUMEN.html** из исходников и копирует публичные файлы в `dist/`; их можно разместить на любом статическом хостинге. После изменения игры выполни `npm run build` и включи обновлённый `LUMEN.html` в коммит. Вручную редактируй исходники, а не собранный HTML. GitHub Actions проверяет тесты, сборку и актуальность HTML при push в `main` и в pull request.

## Публикация сайта через GitHub Pages

Код можно запускать локально сразу после клонирования. Чтобы дополнительно получить сайт, в репозитории открой **Settings → Pages → Build and deployment**, выбери **Deploy from a branch**, ветку **main**, каталог **/ (root)** и нажми **Save**. После успешного развёртывания адрес появится в этом разделе. Все пути относительные и поддерживают размещение в подпапке репозитория.

## Устройство проекта

```text
LUMEN.html           готовая игра в одном файле — открывается двойным щелчком
index.html           интерфейс и меню
style.css            адаптивные стили
src/core.js          игровая логика без отрисовки
src/game.js          камера, Canvas 2D, интерфейс, управление и звук
src/cosmetics.js     темы, облики, достижения и прогресс
scripts/server.mjs   локальный HTTP-сервер на Node.js
scripts/build.mjs    сборка одного HTML-файла и статического сайта
tests/core.test.mjs   тесты игровой логики
```

Все изображения рисуются кодом на Canvas; звуки создаются Web Audio API. Нет CDN, аналитики, сетевых запросов к сторонним сервисам и внешних игровых движков.
