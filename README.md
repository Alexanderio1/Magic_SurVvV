# ✧ LUMEN — Последний круг

Небольшая браузерная игра на выживание в духе Magic Survival / Vampire Survivors: управляй магом, уклоняйся от врагов, собирай опыт и усиливай автоматические заклинания. Оригинальные название, графика и код; сторонние игровые ресурсы не используются.

**Цель:** пережить 3 минуты и встретить рассвет. Игра работает на компьютере и телефоне, не требует аккаунта или сервера с базой данных.

## Установка и запуск

Нужны [Git](https://git-scm.com/downloads) и [Node.js 20+](https://nodejs.org/) (рекомендуется Node.js 24 LTS).

```bash
git clone https://github.com/Alexanderio1/Magic_SurVvV.git
cd Magic_SurVvV
npm start
```

Открой **http://localhost:5173** в современном Chrome, Firefox, Edge или Safari. Для остановки нажми `Ctrl+C` в терминале. `npm install` не нужен: внешних зависимостей нет.

Альтернативный запуск с Python 3, из каталога проекта:

```bash
python3 -m http.server 5173 --bind 127.0.0.1
```

На Windows команда может называться `python` или `py`. Открывать `index.html` двойным щелчком не следует: браузер должен загружать JavaScript-модули через HTTP.

Для игры с телефона в той же локальной сети запусти сервер на всех интерфейсах:

```bash
# macOS / Linux
HOST=0.0.0.0 npm start
```

```powershell
# Windows PowerShell
$env:HOST="0.0.0.0"; npm start
```

На телефоне открой `http://<локальный-IP-компьютера>:5173`; доступ должен быть разрешён локальным брандмауэром. Другой порт задаётся переменной `PORT`.

## Как играть

| Действие | Компьютер | Телефон |
| --- | --- | --- |
| Движение | WASD / стрелки (любая раскладка) | Джойстик слева |
| Рывок с краткой неуязвимостью | Пробел | Кнопка ↯ справа |
| Пауза / продолжить | P / Esc / кнопка Ⅱ | Кнопка Ⅱ |
| Выбор улучшения | 1, 2, 3 / мышь | Нажатие на карточку |

Стрелы автоматически летят к ближайшим врагам. Подбирай зелёные осколки: каждый уровень позволяет выбрать одно из трёх случайных улучшений. Доступны урон, скорость стрельбы, дополнительные стрелы, круговой взрыв, вращающиеся луны, скорость движения, притяжение осколков, здоровье и регенерация. Новый уровень также восстанавливает немного здоровья.

Каждые 45 секунд начинается более плотная волна. Постепенно появляются быстрые духи и тяжёлые враги. Рывок восстанавливается за 4 секунды. На 03:00 наступает победа; при потере всего здоровья можно сразу начать новый забег.

При уходе с вкладки игра ставится на паузу. Лучший результат хранится локально в браузере; при очистке данных сайта он сбросится. Звук по умолчанию выключен, его можно включить в шапке.

## Проверка и сборка

```bash
npm test
npm run build
```

Тесты проверяют движение, боевую механику, опыт, улучшения, рывок, урон, паузу и победу. Сборка копирует публичные файлы в `dist/`; их можно разместить на любом статическом хостинге. GitHub Actions запускает тесты и сборку при push в `main` и в pull request.

## Публикация сайта через GitHub Pages

Код можно запускать локально сразу после клонирования. Чтобы дополнительно получить сайт, в репозитории открой **Settings → Pages → Build and deployment**, выбери **Deploy from a branch**, ветку **main**, каталог **/ (root)** и нажми **Save**. После успешного развёртывания адрес появится в этом разделе. Все пути относительные и поддерживают размещение в подпапке репозитория.

## Устройство проекта

```text
index.html           интерфейс и меню
style.css            адаптивные стили
src/core.js          игровая логика без отрисовки
src/game.js          Canvas 2D, управление, звук, рекорд
scripts/server.mjs   локальный HTTP-сервер на Node.js
scripts/build.mjs    сборка статических файлов
tests/core.test.mjs   тесты игровой логики
```

Все изображения рисуются кодом на Canvas; звуки создаются Web Audio API. Нет CDN, аналитики, сетевых запросов к сторонним сервисам и внешних игровых движков.
